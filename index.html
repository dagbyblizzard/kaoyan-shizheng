一、【当日】习近平会见印尼总统普拉博沃：启动中印尼CEPA谈判

1. 事实清单

  • 时间地点：2026年11月20日上午，深圳。普拉博沃来华出席亚太经合组织（APEC）领导人非正式会议。
  • 核心成果：两国元首共同宣布启动中印尼全面经济伙伴关系协定（CEPA）谈判。
  • 中方表述：中印尼命运共同体建设迈上新台阶；两国都面临推进现代化、实现国家长治久安、营造良好外部环境的共同任务；要夯实政治互信基石，加强执政党治国理政经验交流；做大互利合作蛋糕，抓好雅万高铁、"两国双园"等大项目，深化能矿资源、人工智能、数字经济、清洁能源合作，积极构建蓝色伙伴关系，早日达成全方位、高水平的CEPA。
  • 多边层面：在联合国、APEC、中国—东盟等框架内加强协调；支持东盟加强团结和战略自主；引领全球南方联合自强；改革完善全球治理。
  • 印尼表态：坚定奉行一个中国政策，认为台湾是中华人民共和国的一个省；欢迎中资企业投资，提供可靠稳定、可预期的营商环境；支持习近平主席提出的四大全球倡议；愿在联合国、世界人工智能合作组织、国际调解院等加强协调。
  • 出席：蔡奇、王毅、黄坤明等。

2. 考点对接（至少两个板块，写明为什么）

  • 当代世界经济与政治：这是周边外交的典型样本。中国周边外交坚持"亲诚惠容"理念，坚持与邻为善、以邻为伴。印尼是东盟最大经济体、海上丝绸之路首倡之地，中印尼关系对"中国—东盟"整体合作具有示范效应。命运共同体在这里不是抽象口号，而是通过CEPA谈判、雅万高铁、"两国双园"、蓝色伙伴关系等具体机制落地。
  • 毛中特（习近平新时代中国特色社会主义思想）：对接高水平对外开放与双循环新发展格局。CEPA谈判属于制度型开放的范畴，通过规则、规制、管理、标准等对接，把"开放"从商品和要素流动层面推进到制度层面。同时，雅万高铁是中国高铁"走出去"的标志性项目，体现高质量共建"一带一路"。
  • 马原：用联系的普遍性与世界历史理论理解——生产社会化和国际分工使各国形成普遍交往，中印尼的产业互补（能矿、数字经济、绿色能源）是客观联系的表现。用矛盾普遍性与特殊性理解——两国国情不同、制度不同，但面临现代化、长治久安、良好外部环境的共同任务，这就是"共性寓于个性之中"。

3. 命题角度

  • 选择题陷阱：
  • CEPA是"启动谈判"，不是"签署"或"生效"——这是最容易设置的干扰项。
  • "蓝色伙伴关系"是海洋合作的新提法，不要与"蓝色经济通道"混淆。
  • 雅万高铁是中印尼标志性项目，不要与中老铁路、中泰铁路混淆。
  • 印尼对台湾的表述是"一个省"，不是"一个中国原则"的泛泛表述，选择题可能考原话。
  • 分析题设问：为什么说周边是中国外交的优先方向？请结合中印尼关系说明。

答题链：地理相邻（地缘）→ 发展利益交融（产业链、能矿、基建）→ 安全关切（海上、地区稳定）→ 理念引领（亲诚惠容、命运共同体）→ 机制支撑（CEPA、中国—东盟、APEC）→ 世界意义（全球南方、全球治理）。

  • 可替换设问：
  1. 如何理解"支持东盟加强团结和战略自主"？
  2. 中印尼合作对"全球南方"联合自强有何意义？
  3. 从"硬联通"到"心联通"，中印尼合作体现了什么？

4. 金句

  • "命运共同体建设迈上新台阶，为两国推进各自现代化提供了重要助力。"
  • "做大互利合作蛋糕。"
  • "支持东盟加强团结和战略自主，维护地区安全和发展，引领全球南方联合自强。"

5. 易错点

  • CEPA ≠ 自贸协定（FTA）：CEPA是更全面的经济伙伴关系安排，覆盖贸易、投资、服务、数字经济等；且目前只是"启动谈判"。
  • "两国双园"不是两个园区随便叫，而是中印尼产业合作的具体平台（福建元洪投资区与印尼民丹、巴淡等园区），选择题若出现具体地名要核对。
  • "全球南方"不是地理概念，而是发展中国家和新兴市场国家的集合，考试中常与"南南合作"联动。

（来源：人民日报2026年11月21日头版）

二、【当日】习近平会见新加坡总理黄循财：中新自贸协定4.0版谈判启动

1. 事实清单

  • 时间地点：2026年11月20日上午，深圳。黄循财来华出席APEC领导人非正式会议。
  • 关系定位：推动中新"全方位高质量的前瞻性伙伴关系"不断迈上新台阶。
  • 四个"要做"：
  1. 相互信任的真诚朋友：筑牢政治互信，维护共同利益，支持彼此走符合自身国情的发展道路；
  2. 引领创新的发展伙伴：高质量共建"一带一路"，高水平运营重大合作项目，启动自贸协定4.0版谈判，在数字经济、绿色发展、人工智能等领域打造标志性成果，推动双边合作向新、向智、向绿转型；
  3. 互学互鉴的友好近邻：深化治国理政经验交流和党际合作，扩大人文交流；
  4. 维护国际公平正义的进步力量：在APEC、中国—东盟等框架内协调，把稳东亚合作正确方向，共建亚太共同体和人类命运共同体。
  • 新方表态：坚定奉行一个中国政策，反对"台独"；支持人类命运共同体理念和四大全球倡议；祝贺中方主办中俄美三国元首会晤。
  • 配套动作：丁薛祥将访问新加坡并主持中新双边合作机制会议。

2. 考点对接

  • 当代世界经济与政治：新加坡是"小国大外交"的典型，中新关系是中国与东盟国家关系的"标杆"。四个"要做"实际上回答了一个问题：不同大小、不同制度国家如何相处？答案是相互尊重、平等互利、互学互鉴。
  • 毛中特：制度型开放是核心。自贸协定4.0版谈判意味着从"边境措施"（关税、通关）走向"边境后措施"（规则、标准、数字贸易、绿色标准）。"向新、向智、向绿"对应新质生产力、数字经济、绿色发展三条主线。
  • 马原：矛盾的特殊性——新加坡国土小、资源少，但金融、航运、治理能力强，这叫"具体问题具体分析"；同时，中新合作又体现联系的普遍性，两国在产业链、金融、人才上高度互补。

3. 命题角度

  • 选择题陷阱：
  • 中新自贸协定是"4.0版谈判启动"，不是"升级议定书签署"。
  • "全方位高质量的前瞻性伙伴关系"是中新定位，不要与"中印尼命运共同体""中澳全面战略伙伴关系"混用。
  • "向新、向智、向绿"三个方向要能对应：新＝新质生产力/新兴领域，智＝人工智能/数字经济，绿＝绿色低碳。
  • 分析题设问：中新合作为什么能成为不同制度国家互学互鉴的典范？

答题链：相互尊重（不干涉内政、尊重发展道路）→ 利益交融（贸易、投资、金融、产业链）→ 机制保障（自贸协定、双边合作机制会议、党际交流）→ 理念共识（多边主义、人类命运共同体）→ 示范意义（小国与大国、不同制度国家相处）。

  • 可替换设问：
  1. 如何理解"制度型开放"？请结合中新自贸协定4.0版谈判说明。
  2. "向新、向智、向绿"体现了哪些新发展理念？

4. 金句

  • "做相互信任的真诚朋友、引领创新的发展伙伴、互学互鉴的友好近邻、维护国际公平正义的进步力量。"
  • "推动双边合作向新、向智、向绿转型。"
  • "把稳东亚合作正确方向。"

5. 易错点

  • "前瞻性"是中新关系定位的关键词，考试若把"前瞻性"换成"战略性"就是错的。
  • 新加坡不是"东盟轮值主席国"的固定表述对象，涉及东盟时要区分"东盟中心地位"与"大国平衡"。
  • 4.0版谈判涉及数字贸易、绿色经济等新议题，不要只答"降关税"。

（来源：人民日报2026年11月21日头版）

三、【当日】中澳关系：元首会见＋第十一轮总理年度会晤，2027年"中澳旅游年"

1. 事实清单

  • 元首会见：2026年11月20日上午，习近平在深圳会见澳大利亚总理阿尔巴尼斯。
  • 关系判断：中澳关系稳定发展，各领域交流合作持续深化；两国"既没有历史恩怨，也没有根本利益冲突"，理应成为相互信任、彼此成就的合作伙伴。
  • 时间节点：明年（2027年）是中澳建交55周年；双方已商定把2027年设为"中澳旅游年"。
  • 四点意见：
  1. 在变乱交织的国际形势中增进彼此互信，坚持全面战略伙伴关系定位，理性、友善看待对方，照顾彼此核心利益和重大关切；
  2. 在谋求各自发展中深化互利合作，推进农业、能源、矿产等传统合作，加强绿色经济、新能源、数字产业、人工智能、应对气候变化等新兴合作；
  3. 在扩大人文交流中促进两国友好，办好2027年"中澳旅游年"，鼓励地方、民间、青年、媒体、智库交流；
  4. 在应对全球性挑战中加强多边协作，推进亚太共同体建设，维护以联合国为核心的国际体系和以国际法为基础的国际秩序。
  • 总理会晤：11月20日下午，李强在北京钓鱼台国宾馆同阿尔巴尼斯举行第十一轮中澳总理年度会晤；双方发表《中澳总理年度会晤联合成果声明》。
  • 澳方表态：坚持一个中国政策；愿做"不同制度国家发展建设性关系的典范"；祝贺中方主办APEC会议和中俄美元首会晤。

2. 考点对接

  • 当代世界经济与政治：中澳关系是"大国与中等强国"关系的样本。四点意见的核心是相互尊重、求同存异、互利合作、管控分歧，对应新型国际关系"相互尊重、公平正义、合作共赢"。
  • 史纲：1972年中澳建交，2027年是55周年。中澳关系经历了建交、发展、波折、转圜的过程，说明国家间关系归根到底由国家利益决定，同时需要相互尊重的政治基础。
  • 毛中特：对接高水平对外开放与贸易强国。中澳经济互补性强（澳方资源、农产品；中方市场、制造、新能源），合作是"相互赋能"而非零和博弈。
  • 马原：矛盾的对立统一——中澳有分歧（制度、价值观、地区安全），但更有共同利益（贸易、气候、地区稳定），斗争性与同一性在一定条件下相互转化；具体问题具体分析——对不同领域的分歧采取不同处理方式。

3. 命题角度

  • 选择题陷阱：
  • 2027年是建交55周年（1972年建交），不是50周年。
  • "中澳旅游年"是2027年，不是2026年。
  • 中澳定位是"全面战略伙伴关系"（2014年升级），不是"全面战略协作伙伴关系"（那是中俄）。
  • 第十一轮总理年度会晤的地点是北京钓鱼台，元首会见在深圳——地点容易混。
  • 分析题设问：中澳关系改善发展对处理不同制度国家关系有何启示？

答题链：坚持相互尊重（不把自己的制度强加于人）→ 坚持互利共赢（经贸压舱石）→ 妥善管控分歧（不使分歧定义双边关系）→ 加强多边协作（多边主义、自由贸易）→ 树立"建设性关系"典范。

  • 可替换设问：
  1. 如何理解"既没有历史恩怨，也没有根本利益冲突"？
  2. 从"经济互补"角度说明中澳合作的内生动力。

4. 金句

  • "中澳两国既没有历史恩怨，也没有根本利益冲突，理应成为相互信任、彼此成就的合作伙伴。"
  • "不能让分歧干扰双边关系。"
  • "使澳中关系成为不同制度国家发展建设性关系的典范。"（澳方表述）

5. 易错点

  • 中澳 vs 中俄定位：中澳＝全面战略伙伴关系；中俄＝新时代全面战略协作伙伴关系；中新（加坡）＝全方位高质量的前瞻性伙伴关系。三者不能混。
  • "旅游年"不是"交流年"，年份是2027。
  • 中澳总理年度会晤是第十一轮，不是首届。

（来源：人民日报·习近平会见阿尔巴尼斯；人民日报·第十一轮中澳总理年度会晤）

四、【年度重点】党的二十届五中全会：全面从严治党《决定》

1. 事实清单

  • 时间地点：2026年10月26日至29日，北京。
  • 核心文件：审议通过《中共中央关于持之以恒推进全面从严治党若干重大问题的决定》。
  • 历史节点：2026年是建党105周年，也是"十五五"开局起步的关键节点。
  • 重要定位：《决定》把"增强共产党人的党性"摆在各项战略任务和重大举措的首位，明确提出"增强党性是全面从严治党的根本性任务"，强调把加强党性修养作为终身课题。
  • 五个方面部署：强化对党忠诚教育；坚持用党的创新理论凝心铸魂；用党的优良传统和中华优秀传统文化涵养党性；在实践中锤炼党性；加强党性鉴别。
  • 说明：习近平总书记就《决定（讨论稿）》向全会作了说明。

2. 考点对接

  • 毛中特（党的建设）：对接全面从严治党与党的自我革命。自我革命是中国共产党跳出治乱兴衰历史周期率的第二个答案（第一个答案是毛泽东同志在"窑洞对"中提出的"让人民来监督政府"）。新时代党的建设总要求以党的政治建设为统领，把制度建设贯穿其中，深入推进反腐败斗争。
  • 马原：内因与外因——全面从严治党，根本在于党的自我净化、自我完善、自我革新、自我提高，这是内因；人民群众监督、外部环境是外因，外因通过内因起作用。实践与认识——党性不是随党龄、职务自然增长的，必须在严肃的党内生活和工作实践中锤炼，体现"实践是认识的基础"。量变质变——党性修养是终身课题，靠经常性教育、持续性锻炼。
  • 史纲：延安整风、党的三大优良作风（理论联系实际、密切联系群众、批评与自我批评）、"窑洞对"、七届二中全会"两个务必"——这些都是理解"自我革命"的历史脉络。
  • 思修：理想信念是共产党人精神上的"钙"；对党忠诚是首要政治品质；政德建设（明大德、守公德、严私德）。

3. 命题角度

  • 选择题陷阱：
  • 五中全会的主题是"全面从严治党"，不是"十五五"规划（"十五五"规划建议是二十届四中全会通过的）。
  • 《决定》的全称要记准："关于持之以恒推进全面从严治党若干重大问题的决定"。
  • "增强党性"被定位为"根本性任务"，不是"基础性任务""首要任务"。
  • "增强党性"摆在各项战略任务和重大举措的首位，不是第二位。
  • 分析题设问：为什么说"增强党性是全面从严治党的根本性任务"？

答题链：党性是马克思主义政党本质属性的集中体现（是什么）→ 党性强则"正气内存、邪不可干"，党性弱则易被侵蚀（为什么）→ 对党忠诚、理想信念、人民立场、实事求是、政德、廉洁（具体要求）→ 终身课题、常修常炼（怎么做）→ 确保党不变质、不变色、不变味（意义）。

  • 可替换设问：
  1. 如何理解自我革命是跳出历史周期率的第二个答案？
  2. 结合《决定》，说明思想建党和制度治党如何同向发力。

4. 金句

  • "增强党性是全面从严治党的根本性任务。"
  • "党性是党员、干部立身、立业、立言、立德的基石。"
  • "党性不可能随着党龄的增加而自然增强，也不可能随着职务的升迁而自然增强。"
  • "确保党永远不变质、不变色、不变味。"

5. 易错点

  • 四中全会 vs 五中全会：四中全会（2025年10月）通过"十五五"规划建议；五中全会（2026年10月）通过全面从严治党《决定》。这是最容易混的一组。
  • "两个答案"：第一个是"人民监督"，第二个是"自我革命"，顺序不能反。
  • "窑洞对"发生在延安时期（1945年黄炎培访问延安），不是西柏坡。
  • 《决定》不是"关于加强党的建设"的泛泛文件，关键词是"持之以恒"和"全面从严治党"。

（来源：人民日报2026年11月20日理论版；光明日报2026年10月31日）

五、【年度重点】纪念长征胜利90周年："五个必须"与新时代长征路

1. 事实清单

  • 时间地点：2026年10月22日上午，北京人民大会堂隆重举行纪念中国工农红军长征胜利90周年大会。
  • 出席：习近平发表重要讲话；李强、赵乐际、王沪宁、蔡奇、丁薛祥、李希、韩正出席；赵乐际主持；约3000人参加。
  • 长征基本事实：1934年10月至1936年10月，党领导红军第一、第二、第四方面军和第二十五军，纵横十余省，长驱二万五千里，粉碎上百万敌军围追堵截，胜利实现北上抗日的战略转移。
  • 四个"制胜之道"：依靠党的正确领导（党的正确领导和毛泽东同志核心地位的确立具有决定性意义）；依靠坚定的革命意志；依靠独立自主、实事求是；依靠广大人民群众支持。
  • 伟大长征精神：彰显忠诚的力量、真理的力量、正义的力量、团结的力量，是中国共产党人精神谱系的重要组成部分。
  • "五个必须"：
  1. 必须坚守党的理想信念宗旨，全面贯彻习近平新时代中国特色社会主义思想，牢记初心使命，紧紧依靠人民创造新的历史伟业；
  2. 必须坚定不移推动高质量发展，不断满足人民日益增长的美好生活需要，统筹推进"五位一体"总体布局，协调推进"四个全面"战略布局，促进全体人民共同富裕；
  3. 必须勇于进行具有许多新的历史特点的伟大斗争，更好统筹发展和安全；
  4. 必须加快把人民军队建成世界一流军队，坚持党对人民军队的绝对领导，如期实现建军一百年奋斗目标；
  5. 必须坚持党的领导、加强党的建设，持之以恒推进全面从严治党。

2. 考点对接

  • 史纲：长征是中国革命史上的伟大转折。遵义会议（1935年1月）确立了毛泽东同志在党中央和红军的领导地位，是党的历史上一个生死攸关的转折点，标志着中国共产党在政治上开始走向成熟。长征的胜利，实现了中国革命重心由南方到北方的战略转移，为抗日民族统一战线的形成奠定了基础。
  • 毛中特：把长征精神与中国式现代化贯通。"五个必须"实际上是把革命年代的制胜之道转化为新时代的实践要求：高质量发展、共同富裕、统筹发展和安全、强军目标、全面从严治党——这正是当前考研政治的五条主线。
  • 马原：人民群众是历史的主体和创造者——长征胜利靠人民群众支持，这是群众史观的生动体现。实践与认识——长征是在极端困难条件下的伟大实践，遵义会议对"左"倾错误的纠正体现了认识在实践中深化。矛盾——长征途中敌我力量悬殊，但通过战略战术的灵活调整（四渡赤水等），实现了矛盾双方的转化。
  • 思修：理想信念是精神之"钙"；爱国主义与革命精神；艰苦奋斗、团结协作。

3. 命题角度

  • 选择题陷阱：
  • 长征时间：1934年10月—1936年10月，不是1935年。
  • 遵义会议是1935年1月，是"生死攸关的转折点"，不是"长征胜利的标志"。
  • "五个必须"中，第4条是"建军一百年奋斗目标"（2027年），第5条是"全面从严治党"——顺序和对应内容要记准。
  • 纪念大会地点是人民大会堂，主持人是赵乐际。
  • 分析题设问：如何理解"长征胜利是必然的"？请结合"四个制胜之道"说明。

答题链：党的正确领导（根本保证，遵义会议确立毛泽东核心地位）→ 坚定理想信念（精神动力）→ 独立自主、实事求是（思想路线，马克思主义中国化）→ 人民群众支持（力量源泉）→ 伟大长征精神（精神谱系）→ 结论：必然性寓于这些主客观条件的统一之中。

  • 可替换设问：
  1. 结合"五个必须"，说明新时代如何走好新的长征路。
  2. 为什么说长征精神"跨越时空、历久弥新"？

4. 金句

  • "长征胜利是必然的，其中蕴含着党和人民军队铿锵前进的制胜之道。"
  • "精神所在，就是力量所在。"
  • "长征的历史从未远去，长征的路在不断延伸。"
  • "新征程是充满光荣和梦想的远征，是党和人民的新长征。"

5. 易错点

  • 长征≠抗战：长征是1934—1936年，全面抗战爆发是1937年，不要混。
  • "二万五千里"是中央红军（红一方面军）的长征里程，不是所有红军部队的合计。
  • "建军一百年奋斗目标"时间是2027年（1927年南昌起义建军），不是2035年。
  • "五个必须"不是"五个坚持""五个必由之路"，表述要准确。

解析：双方宣布启动的是"全面经济伙伴关系协定（CEPA）谈判"，不是自贸协定（FTA），也不是蓝色经济或数字经济专项协定。C项"蓝色伙伴关系"是合作方向，不是协定名称；D项是合作领域之一。此题还提示：CEPA目前只是"启动谈判"，未签署、未生效。

分析题

材料：习近平在纪念长征胜利90周年大会上指出，"长征胜利是必然的"，并围绕弘扬伟大长征精神、走好新的长征路提出"五个必须"。

问题：
（1）结合"四个制胜之道"，说明为什么说"长征胜利是必然的"。
（2）运用"五个必须"，分析新时代走好新的长征路的要求。

参考答案与评分点：

（1）为什么"必然"（6分）：

  • 党的正确领导是根本保证。遵义会议确立毛泽东同志在党中央和红军的领导地位，是生死攸关的转折点，使党在政治上走向成熟。（2分）
  • 坚定的革命意志是精神动力。崇高理想和坚定信念使红军在极端困难条件下不可战胜。（1分）
  • 独立自主、实事求是是思想路线。马克思主义基本原理同中国具体实际相结合，才能解决中国问题。（1分）
  • 人民群众支持是力量源泉。植根人民、保持血肉联系，是党和人民军队的坚强后盾。（1分）
  • 结论：必然性不是宿命，而是上述主客观条件共同作用的結果，是历史规律性与主体能动性的统一。（1分）

（2）"五个必须"的要求（6分）：

  • 坚守理想信念宗旨，全面贯彻习近平新时代中国特色社会主义思想，牢记初心使命；（1分）
  • 推动高质量发展，满足人民美好生活需要，促进全体人民共同富裕；（1分）
  • 进行具有许多新的历史特点的伟大斗争，统筹发展和安全；（1分）
  • 建设世界一流军队，坚持党对人民军队的绝对领导，实现建军一百年奋斗目标；（1分）
  • 坚持党的领导、加强党的建设，持之以恒推进全面从严治党；（1分）
  • 总体点题：把长征精神转化为中国式现代化的实践动力，走好新时代的长征路。（1分）

答题提示：分析题要先亮原理/观点，再结合材料，最后落到"中国式现代化"和"民族复兴"的高度，避免只罗列"五个必须"。

2. 金句与判断（分析题可直接引用）

  • "大国和则世界安，大国斗则世界乱。"
  • "'修昔底德陷阱'绝不是宿命，关键要看主要大国如何抉择。"

  • "以对话聚共识，以担当迎挑战，以合作促和平。"

3. 知识点对接

三、习近平对老龄工作作出重要指示；全国老龄工作会议召开

1. 事实清单

  • 全国老龄工作会议11月18—19日在北京召开，传达习近平重要指示；李强出席会议并讲话。
  • 指示核心：深入实施积极应对人口老龄化国家战略，坚持政府、市场、社会、家庭协同发力，加强老年人社会保障、养老服务、健康服务、社会参与，大力发展银发经济，建设老年友好社会。
  • 李强提出"四个把握"：
  1. 把握年龄和健康状况差异 → 老有所养与老有所为相统筹；
  2. 把握经济条件差异 → 服务保障梯度供给；
  3. 把握养老方式差异 → 居家、社区、机构服务贯通协调；
  4. 把握城乡区域分布差异 → 政策均衡性、精准性。
  • 目标节点：锚定"十五五"目标任务，解决老年人急难愁盼问题。

2. 知识点对接

  • 毛中特：以人民为中心的发展思想；在发展中保障和改善民生；共同富裕（中国式现代化本质要求）；以人口高质量发展支撑中国式现代化；社会保障体系"覆盖全民、统筹城乡、公平统一、安全规范、可持续"。
  • 马原：矛盾的特殊性原理 → 具体问题具体分析（"四个把握"就是分层分类）；人民群众是历史的主体和创造者。
  • 思修：孝老爱亲的家庭美德；中华优秀传统文化"老吾老以及人之老"；社会主义核心价值观。
  • 易错："银发经济"既是民生事业，也是发展新动能；不是单纯的"养老负担"论。

3. 命题角度

  • 选择题：会议时间地点、指示中的"四个协同"、"四个把握"的具体对应。
  • 分析题：为什么说发展银发经济"既是民生工程，也是发展工程"？答题链：人口结构变化（客观趋势）→ 民生属性（以人民为中心、共同富裕）→ 经济属性（扩大内需、培育新增长点、有效市场与有为政府结合）→ 辩证统一（在发展中保障和改善民生）。

四、年度重点①：2026年全国两会与"十五五"规划纲要

1. 事实清单

  • 马原：量变与质变（"十五五"为2035远景目标打基础）；生产力与生产关系、经济基础与上层建筑矛盾运动；系统观念。
  • 时政选择：GDP目标4.5%—5%；20项指标；"十五五"起止2026—2030；四中全会《建议》→ 两会《纲要》的法定程序。

  • 分析题：如何理解"十五五"是"夯实基础、全面发力"的关键时期？→ 从2035远景目标倒推、从主要矛盾变化、从高质量发展主题展开。

七、今日一题

选择题1

2026年11月19日，亚太经合组织第三十三次领导人非正式会议在深圳举行。习近平发表的重要讲话题目是（ ）

A.《建设亚太共同体，续写"亚太奇迹"新篇章》
B.《携手构建亚太命运共同体》
C.《开放合作，共创亚太美好未来》
D.《推动亚太自由贸易区建设》

答案：A。 解析：会议主题是"建设亚太共同体，促进共同繁荣"，讲话标题是《建设亚太共同体，续写"亚太奇迹"新篇章》，二者要区分。B、C为形似干扰项；D是会议议题之一，不是讲话标题。

选择题2

习近平提出携手搭建亚太共同体的"四梁八柱"，下列不属于"四梁八柱"的是（ ）

A. 强化经贸支柱
B. 升级联通支柱
C. 打造创新支柱
D. 筑牢安全支柱

答案：D。 解析："四梁八柱"为经贸、联通、创新、发展四大支柱。安全合作体现在"发展支柱"的相关内容中，但"安全支柱"不是本次表述。

分析题（口述3分钟）

材料：习近平在APEC会议上指出，要"构建开放而不排他、融合而不分割的合作格局"。

问题：运用唯物辩证法联系的观点，说明为什么亚太各国"越来越成为你中有我、我中有你的命运共同体"。

答题框架：

  1. 原理：联系具有普遍性、客观性、多样性；世界历史理论揭示，生产社会化和国际分工使各民族进入普遍交往。
  2. 展开：产业链供应链、资本、技术、人员跨境流动，使各国利益深度交融；"脱钩断链"违背客观联系，必然损人害己。
  3. 方法论：坚持系统观念，用综合的、整体的思维方式认识世界；共商共建共享。
  4. 结论：开放包容、合作共赢是唯一正确选择，必须推动构建人类命运共同体。
