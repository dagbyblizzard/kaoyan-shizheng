一、【押题】雄安新区高质量建设

1. 事件/政策事实

  • 考察：2026年3月23日，习近平在河北雄安新区考察，并主持召开深入推进雄安新区高质量建设和发展座谈会。
  • 首要功能定位：北京非首都功能疏解集中承载地（zz25s）。
  • 激发活力的重点：要素资源合理集聚（zz26s）。
  • 战略定位：雄安新区是千年大计、国家大事；是京津冀协同发展的重要一环；坚持高质量发展，建设创新之城、绿色之城、智慧之城。
  • 2026年节点：“十五五”开局之年，雄安建设进入高质量建设和发展新阶段。

2. 考点对接

  • 毛中特·区域协调发展：京津冀协同发展是重大国家战略；雄安新区是疏解北京非首都功能的集中承载地，体现优化区域经济布局、城市群协同。
  • 毛中特·高质量发展：创新驱动、绿色低碳、智慧城市；新质生产力；人民城市理念。
  • 马原：系统观念——疏解、承接、建设、发展是一个系统；矛盾——北京“大城市病”与雄安“承接”是矛盾的两个方面，通过疏解实现转化。

3. 可能题型

  • 选择题陷阱：
  • 首要功能定位是“北京非首都功能疏解集中承载地”，不是“全面深化改革开放试验区”（那是深圳/浦东的表述）。
  • 激发活力的重点是“要素资源合理集聚”，不是“改革创新”（改革创新是动力）。
  • 雄安新区属于河北省，不是北京市。
  • 座谈会是2026年3月23日，不是2017年设立时。
  • 分析题设问：为什么说雄安新区是“千年大计、国家大事”？

答题链：疏解北京非首都功能 → 京津冀协同发展 → 优化城市布局 → 高质量发展/新质生产力 → 中国式现代化。

  • 可替换设问：
  1. 雄安新区与京津冀协同发展的关系。
  2. “要素资源合理集聚”体现了什么经济规律？

4. 【肖秀荣·提法】

  • zz25s：雄安新区的首要功能定位，是北京非首都功能疏解集中承载地。
  • zz26s：激发雄安新区活力的重点，是要素资源合理集聚。

5. 金句

  • “千年大计、国家大事。”
  • “北京非首都功能疏解集中承载地。”
  • “建设创新之城、绿色之城、智慧之城。”

6. 易错点

  • 雄安新区不是“首都副中心”（北京城市副中心在通州）。
  • 首要功能定位不是“科技创新中心”“金融中心”。
  • “疏解”不是“搬迁”：是功能疏解，不是把所有产业都搬过去。
  • 雄安新区2017年设立，2026年是建设新阶段，不是“新设立”。

（来源：手册 zz25s、zz26s；2026.3.23 雄安考察官方报道）

二、【押题】新时代社会工作与基层治理

1. 事件/政策事实

  • 文件：2026年7月24日，中共中央、国务院《关于加强新时代社会工作的意见》公开发布。
  • 定位：社会工作是党和国家工作的重要组成部分，事关党长期执政和国家长治久安，事关社会和谐稳定和人民幸福安康。
  • 突出抓好：新经济组织、新社会组织、新就业群体党的建设（“三新”党建）（zz30s）。
  • 重点任务：党建引领基层治理和基层政权建设；凝聚服务群众工作；行业协会商会改革；社会工作人才队伍建设；志愿服务。
  • 目标：构建共建共治共享的社会治理格局，提升社会治理现代化水平。

2. 考点对接

  • 毛中特·社会治理：社会治理现代化；共建共治共享；党建引领基层治理；以人民为中心。
  • 毛中特·党的建设：“三新”党建是新兴领域党建的重点，扩大党的组织覆盖和工作覆盖。
  • 马原：联系的观点——社会治理是系统工程；人民群众是历史的主体——依靠群众、服务群众。

3. 可能题型

  • 选择题陷阱：
  • 文件是《关于加强新时代社会工作的意见》，2026年7月24日公开发布，不是“印发”。
  • 突出抓好的是“新经济组织、新社会组织、新就业群体党的建设”，不是“社区党建”。
  • 社会工作的定位是“事关党长期执政和国家长治久安”，不是“事关经济发展”。
  • 社会治理格局是“共建共治共享”，不是“共商共建共享”（后者是全球治理观）。
  • 分析题设问：为什么要加强新时代社会工作？

答题链：社会结构变化/新业态 → 群众需求多元化 → 党建引领 → 基层治理 → 社会和谐稳定 → 党的长期执政。

  • 可替换设问：
  1. “三新”党建为什么是新时代党建的重点？
  2. 社会工作与基层治理现代化的关系。

4. 【肖秀荣·提法】

  • zz30s：加强新时代社会工作，要突出抓好新经济组织、新社会组织、新就业群体党的建设。
  • zzc166/zzc184：基层民主保障群众广泛、直接、有效行使民主权利，是人民当家作主的有效途径，是社会主义民主最广泛的实践。

5. 金句

  • “社会工作是党和国家工作的重要组成部分。”
  • “党建引领基层治理。”
  • “共建共治共享。”

6. 易错点

  • 社会工作不是“社会救济”，也不等于“社区工作”，覆盖更广。
  • “三新”党建不是“两新”党建（两新＝新经济组织、新社会组织；三新＋新就业群体）。
  • 共建共治共享是社会治理格局；共商共建共享是全球治理观，不能混。
  • 社会工作的领导是党的领导，不是“政府主导、社会参与”的简单并列。

（来源：手册 zz30s；2026.7.24《关于加强新时代社会工作的意见》）

三、【押题】就业优先与社会保障

1. 事件/政策事实

  • 规划：2026年7月2日，《扩大消费“十五五”规划》获国务院批复。
  • 提升消费能力的四条（zz134m）：促进高质量充分就业、多渠道促进居民增收、完善社会保障政策、合理增加公共消费。
  • 中央经济工作会议部署（2025年12月）：实施稳岗扩容提质行动，稳定高校毕业生、农民工等重点群体就业；鼓励支持灵活就业人员、新就业形态人员参加职工保险。
  • 定位：就业是最基本的民生；就业优先战略；社会保障是民生安全网。

2. 考点对接

  • 毛中特·民生：以人民为中心；就业优先；社会保障“覆盖全民、统筹城乡、公平统一、安全规范、可持续”；共同富裕。
  • 毛中特·扩大内需：就业—收入—消费的良性循环；消费是内需的主力。
  • 马原：生产力与生产关系——就业是劳动者与生产资料结合；系统观念——就业、收入、社保、消费相互关联。

3. 可能题型

  • 选择题陷阱：
  • 提升消费能力的四条包括“高质量充分就业”，不是“扩大投资”。
  • 就业是“最基本的民生”，不是“最大的民生”（“最大民生”常指就业？注意：官方表述“就业是最大的民生”也常见；本题以“最基本的民生”为准，需看语境）。
  • 稳岗扩容提质行动是中央经济工作会议部署，不是“十五五”规划纲要首次提出。
  • 社会保障体系特征：覆盖全民、统筹城乡、公平统一、安全规范、可持续。
  • 分析题设问：为什么说“就业是最基本的民生”？

答题链：就业是收入来源 → 收入是消费基础 → 消费是内需主力 → 就业稳则社会稳 → 共同富裕 → 以人民为中心。

  • 可替换设问：
  1. 就业、收入、社保、消费如何形成良性循环？
  2. 新就业形态人员参加职工保险的意义。

4. 【肖秀荣·提法】

  • zz134m：着力提升消费能力：促进高质量充分就业、多渠道促进居民增收、完善社会保障政策、合理增加公共消费。

5. 金句

  • “就业是最基本的民生。”
  • “稳岗扩容提质。”
  • “覆盖全民、统筹城乡、公平统一、安全规范、可持续。”

6. 易错点

  • 就业优先不是“增长优先”；就业是民生之本。
  • 社会保障不是“社会福利”的同义词，包括社会保险、社会救助、社会福利、慈善事业等。
  • 新就业形态（平台就业、灵活就业）不是“非正规就业”的贬义表述。
  • 扩大消费不是“刺激消费”，而是提升消费能力、改善消费条件、创新消费场景。

（来源：手册 zz134m；2025.12 中央经济工作会议）

四、【押题】全球文明倡议

1. 事件/政策事实

  • 提出：2023年3月15日，习近平在中国共产党与世界政党高层对话会上提出全球文明倡议。
  • 四个“共同倡导”：
  1. 共同倡导尊重世界文明多样性；
  2. 共同倡导弘扬全人类共同价值；
  3. 共同倡导重视文明传承和创新；
  4. 共同倡导加强国际人文交流合作。
  • 2026年实践：2026世界人工智能大会提出“鼓励包容并蓄、促进文明互鉴”（zz135m）；中国—东盟人文交流；共建“一带一路”人文交流。
  • 定位：全球文明倡议是继全球发展倡议、全球安全倡议、全球治理倡议之后的又一重要公共产品，构成四大全球倡议。

2. 考点对接

  • 当代世界经济与政治：文明交流互鉴；全人类共同价值（和平、发展、公平、正义、民主、自由）；人类命运共同体；真正的多边主义。
  • 毛中特·文化：文化自信；中华文明连续性、创新性、统一性、包容性、和平性；文明大国形象。
  • 马原：矛盾普遍性与特殊性——文明多样性是特殊性，全人类共同价值是普遍性；联系——文明因交流而多彩。

3. 可能题型

  • 选择题陷阱：
  • 全球文明倡议提出于2023年3月15日，不是2022年、2024年。
  • 四个“共同倡导”的顺序：多样性、共同价值、传承创新、人文交流。
  • 全人类共同价值是“和平、发展、公平、正义、民主、自由”，不是“自由、平等、博爱”。
  • 四大全球倡议：发展（2021）、安全（2022）、文明（2023）、治理（2025）。
  • 分析题设问：为什么说“文明因交流而多彩，文明因互鉴而丰富”？

答题链：文明多样性是客观事实 → 交流互鉴是文明发展动力 → 全人类共同价值 → 反对文明冲突论/优越论 → 人类命运共同体。

  • 可替换设问：
  1. 全球文明倡议与“文明冲突论”的对立。
  2. 中华文明的包容性如何体现？

4. 【肖秀荣·提法】

  • zzc206：中国式现代化深深植根于中华优秀传统文化、体现科学社会主义先进本质、借鉴吸收一切人类优秀文明成果、代表人类文明进步的发展方向。
  • zz135m：全球AI治理主张“鼓励包容并蓄、促进文明互鉴”，可作为文明交流互鉴的例证。

5. 金句

  • “文明因交流而多彩，文明因互鉴而丰富。”
  • “尊重世界文明多样性。”
  • “弘扬全人类共同价值。”

6. 易错点

  • 全球文明倡议不是“全球文化霸权”，强调平等、互鉴、对话、包容。
  • 全人类共同价值不是“普世价值”；前者尊重差异，后者常带西方中心论色彩。
  • 文明冲突论是错误思潮，文明差异不等于冲突。
  • 四大全球倡议不是并列提出，时间不同。

（来源：2023.3.15 讲话；手册 zzc206、zz135m）

五、【押题】社会主义核心价值观

1. 事件/政策事实

  • 24字内容：
  • 国家层面：富强、民主、文明、和谐；
  • 社会层面：自由、平等、公正、法治；
  • 个人层面：爱国、敬业、诚信、友善。
  • 定位（zzc302）：是当代中国精神的集中体现；是中国特色社会主义道路、理论、制度、文化的价值表达；凝结着全体人民共同的价值追求。
  • 先进性原因（zzc305）：集中体现了社会主义的本质属性；扎根于中华优秀传统文化的土壤；吸收借鉴了一切人类优秀文化的先进价值。
  • 2026年实践：爱国主义教育法施行两周年；精神文明建设；青年价值观教育；诚信建设。

2. 考点对接

  • 思修·价值观：价值观是人生观的集中体现；社会主义核心价值观是当代中国精神的集中体现；要扣好人生第一粒扣子。
  • 思修·道德：社会公德、职业道德、家庭美德、个人品德；诚信建设。
  • 毛中特·文化：文化自信；培育和践行社会主义核心价值观；以文化人。

3. 可能题型

  • 选择题陷阱：
  • 国家层面是“富强、民主、文明、和谐”，不是“自由、平等、公正、法治”（社会层面）。
  • 个人层面是“爱国、敬业、诚信、友善”，不是“爱国、敬业、诚信、法治”。
  • 社会主义核心价值观是“当代中国精神的集中体现”，不是“中华传统文化的集中体现”。
  • 先进性原因包括“社会主义本质属性”，不是“资本主义优秀文明”。
  • 分析题设问：为什么说社会主义核心价值观是“当代中国精神的集中体现”？

答题链：价值表达（道路/理论/制度/文化）→ 共同价值追求 → 社会主义本质 → 中华优秀传统文化 → 人类优秀文化 → 凝聚民族复兴力量。

  • 可替换设问：
  1. 如何培育和践行社会主义核心价值观？
  2. 社会主义核心价值观与爱国主义教育的关系。

4. 【肖秀荣·提法】

  • zzc302：社会主义核心价值观是当代中国精神的集中体现，是中国特色社会主义道路、理论、制度、文化的价值表达，凝结着全体人民共同的价值追求。
  • zzc305：其先进性原因：集中体现了社会主义的本质属性；扎根于中华优秀传统文化的土壤；吸收借鉴了一切人类优秀文化的先进价值。

5. 金句

  • “扣好人生第一粒扣子。”
  • “当代中国精神的集中体现。”
  • “富强民主文明和谐，自由平等公正法治，爱国敬业诚信友善。”

6. 易错点

  • 社会主义核心价值观不是“社会主义核心价值体系”的简单简称；体系包括指导思想、共同理想、民族精神时代精神、荣辱观。
  • 24字分三个层面，顺序不能乱。
  • “普世价值”不是社会主义核心价值观；后者有社会主义性质。
  • 核心价值观不是“道德”，还包括国家、社会层面的价值目标。

（来源：手册 zzc302、zzc305）

一、【押题】国家发展规划法：规划治理的法治化

1. 事件/政策事实

  • 马原：上层建筑反作用于经济基础——规划法属于上层建筑，通过稳定预期、规范程序反作用于经济社会发展；实践与认识——规划是认识的结晶，又指导新的实践。

  • 2026年5月13—15日：美国总统特朗普对中国进行国事访问，这是历史性会晤；两国元首同意将“中美建设性战略稳定关系”作为两国关系新定位。
  • 四个“稳定”（zz138m）：合作为主的积极稳定、竞争有度的良性稳定、分歧可控的常态稳定、和平可期的持久稳定。
  • 2026年11月19日：习近平在深圳会见特朗普，赋予新定位“基于尊重、公平、对等”的新内涵；双方同意制定行动计划；涉及台湾问题、经贸、禁毒、非法移民遣返、打击电信网络诈骗、人工智能安全风险等。
  • 中方立场：台湾问题是中美关系第一条不可逾越的红线；美方表示不支持“台独”。

2. 考点对接

  • 当代世界经济与政治：新型国际关系（相互尊重、公平正义、合作共赢）、大国关系格局（和平共处、总体稳定、均衡发展）、真正的多边主义。
  • 毛中特·外交：独立自主的和平外交政策；人类命运共同体；相互尊重、和平共处、合作共赢三原则。
  • 马原：矛盾的对立统一——中美既有竞争也有合作，斗争性与同一性相互联结；“竞争有度、分歧可控”就是把握矛盾转化的条件。

3. 可能题型

  • 选择题陷阱：
  • 新定位是“建设性战略稳定关系”，不是“战略合作伙伴关系”“建设性合作关系”。
  • 四个稳定是“合作为主、竞争有度、分歧可控、和平可期”，顺序和定语不能改。
  • 5月是国事访问，11月是深圳会见，两个节点不要混。
  • “基于尊重、公平、对等”是11月会见赋予的新内涵。
  • 分析题设问：如何理解“中美建设性战略稳定关系”？

答题链：大国关系重要性 → 新定位（合作、竞争、分歧、和平四个维度）→ 相互尊重、和平共处、合作共赢 → 管控分歧、行动计划 → 对世界和平稳定的意义。

（一）主观能动性与客观规律性

  1. 尊重客观规律是正确发挥主观能动性的前提；只有发挥主观能动性，才能正确认识和利用客观规律；实践是二者统一的基础。
  2. 正确发挥主观能动性的条件：从实际出发（前提）、实践（根本途径）、一定的物质条件和物质手段。

（二）事物的普遍联系与发展

  1. 联系和发展的观点是唯物辩证法的总观点，集中体现唯物辩证法的总特征。
  2. 联系是事物内部各要素之间和事物之间相互影响、相互制约、相互作用的关系；普遍联系通过中介实现；人们可以发现固有联系，并能动地建立新的联系。
  3. 发展是事物变化中前进的、上升的运动，实质是新事物的产生和旧事物的灭亡。
  4. 新事物合乎历史前进方向、具有远大前途；它否定旧事物中消极腐朽的东西，保留合理的、适应新条件的因素，并添加旧事物不能容纳的新内容；从根本上符合人民群众的利益和要求。

2. 考点对接

  • 毛中特·社会主义市场经济：碳市场是市场机制在环境治理中的运用——通过配额交易形成碳价，把外部性内部化，体现“有效市场＋有为政府”。
  • 马原：价值规律——碳配额作为稀缺资源进入市场，价格随供求变化；生产关系与生产力——绿色低碳转型调整能源结构、产业结构；矛盾——发展与减排、整体与局部、短期与长期的辩证统一。

3. 可能题型

  • 选择题陷阱：
  • 首次扩围的行业是钢铁、水泥、铝冶炼，不是电力（电力是2013年试点、2021年全国市场起点）。
  • 扩围后覆盖60%以上碳排放量，不是“全部”。
  • 全国碳市场2021年7月启动，不是2013年（2013年是地方试点）。
  • “双碳”目标是2030年前碳达峰、2060年前碳中和。
  • 分析题设问：如何理解碳市场是“用市场机制推动绿色低碳转型”？

答题链：外部性理论（碳排放的负外部性）→ 配额交易形成碳价 → 激励先进、鞭策落后 → 降低全社会减排成本 → 与行政手段、法治手段协同 → 服务“双碳”目标。

  • 可替换设问：
  1. 为什么说“双碳”是一场广泛而深刻的经济社会系统性变革？
  2. 碳市场扩围对产业结构升级的影响。

4. 金句

  • “激励先进、鞭策落后。”
  • “扩大全国碳排放权交易市场覆盖范围。”
  • “加快新型能源体系建设，扩大绿电应用。”

5. 易错点

  • 碳市场≠碳税：碳市场是配额交易，碳税是价格型税收工具，二者都是市场化/价格型手段但机制不同。
  • “双碳”不是“碳中和”单目标：碳达峰是前提，碳中和是目标。
  • 扩围行业不要与“七大高耗能行业”混淆，本次是钢铁、水泥、铝冶炼。
  • 全国碳市场只有现货，暂无期货（截至2026年）。

（来源：光明网·全国碳市场扩围；生态环境部答复）

二、【押题】代表法修改与全过程人民民主

1. 事件/政策事实

  • 修改通过：2025年3月11日，十四届全国人大三次会议表决通过《全国人民代表大会关于修改〈中华人民共和国全国人民代表大会和地方各级人民代表大会代表法〉的决定》，自3月12日起施行。
  • 修改背景：代表法1992年制定，这是第四次修改，也是第一次由全国人民代表大会作出修改；涉及277万多名各级人大代表。
  • 核心亮点：总则部分首次写入“践行全过程人民民主”；明确代表“坚持以人民为中心，践行全过程人民民主，始终同人民群众保持密切联系，忠实代表人民的利益和意志，自觉接受人民监督”；进一步拓展和深化“两个联系”（人大常委会组成人员联系代表、代表联系人民群众）。
  • 全过程人民民主：2019年11月，习近平在上海虹桥街道基层立法联系点首次提出；包括民主选举、民主协商、民主决策、民主管理、民主监督五个环节；是“最广泛、最真实、最管用”的社会主义民主。

2. 考点对接

  • 毛中特·政治：全过程人民民主是社会主义民主政治的本质属性；人民代表大会制度是我国的根本政治制度；全过程人民民主实现了过程民主和成果民主、程序民主和实质民主、直接民主和间接民主、人民民主和国家意志相统一。
  • 毛中特·法治：代表法修改体现科学立法、民主立法、依法立法；把党的主张通过法定程序转化为国家意志。
  • 马原：人民群众是历史的主体；上层建筑反作用于经济基础——代表法完善人民代表大会制度，保障人民当家作主。
  • 思修：法治素养、宪法权威、人民主体地位。

3. 可能题型

  • 选择题陷阱：
  • 通过时间是2025年3月11日，施行是3月12日。
  • 是第四次修改，不是首次修改；但是第一次由全国人民代表大会作出修改。
  • 写入的是“践行全过程人民民主”，不是“发展全过程人民民主”（后者是二十大表述）。

5. 易错点

  • 全过程人民民主不是“全体人民直接管理国家”，而是选举、协商、决策、管理、监督各环节的民主。
  • 人民代表大会制度是根本政治制度，不是“基本政治制度”（基本政治制度是政党制度、民族区域自治制度、基层群众自治制度）。

三、【押题】共同富裕与城乡居民增收

四、【押题】西安事变90周年与抗日民族统一战线

1. 事件/政策事实

  • 时间：1936年12月12日凌晨，张学良、杨虎城在西安发动“兵谏”，扣留蒋介石，要求停止内战、一致抗日，史称西安事变（双十二事变）。
  • 和平解决：中共中央从民族大义出发，主张和平解决，派周恩来到西安参加谈判；蒋介石被迫接受停止内战、联共抗日等条件。
  • 历史意义：西安事变的和平解决，基本结束了十年内战，抗日民族统一战线初步形成；1937年9月，国民党公布中共中央提交的国共合作宣言，抗日民族统一战线正式形成。
  • 90周年：2026年12月12日是西安事变90周年（1936—2026），恰在初试前夕。

2. 考点对接

  • 史纲·抗日战争：抗日民族统一战线的形成过程（1935年瓦窑堡会议确立策略→1936年西安事变→1937年9月正式形成）；中国共产党是抗战的中流砥柱；统一战线是党的一大法宝。
  • 毛中特：统一战线是中国共产党凝聚人心、汇聚力量的重要法宝；民族大义与人民立场。
  • 马原：主要矛盾——中日民族矛盾上升为主要矛盾，国内阶级矛盾降为次要矛盾，和平解决西安事变是抓主要矛盾的典范；矛盾转化。

3. 可能题型

  • 选择题陷阱：
  • 西安事变和平解决标志抗日民族统一战线初步形成，不是“正式形成”（正式形成是1937年9月）。
  • 西安事变发生在1936年12月12日，不是1937年。
  • 发动者是张学良、杨虎城，不是“东北军和西北军全体”。
  • 和平解决的关键是中共中央主张和平解决并派周恩来谈判。
  • 分析题设问：为什么中国共产党主张和平解决西安事变？

答题链：民族矛盾上升为主要矛盾 → 逼蒋抗日、停止内战 → 争取国民党内爱国力量 → 维护民族大义 → 促成统一战线 → 体现党的政治成熟和战略眼光。

  • 可替换设问：
  1. 西安事变和平解决与抗日民族统一战线形成的关系。
  2. 为什么说“统一战线是党的重要法宝”？

4. 金句

  • “停止内战，一致抗日。”
  • “西安事变和平解决，抗日民族统一战线初步形成。”
  • “统一战线是中国共产党凝聚人心、汇聚力量的重要法宝。”

5. 易错点

  • 初步形成 vs 正式形成：西安事变（1936.12）初步形成；1937年9月国民党公布国共合作宣言，正式形成。
  • 十年内战结束于西安事变和平解决，不是“七七事变”。
  • 瓦窑堡会议（1935.12）确立抗日民族统一战线策略，不是“西安事变”。
  • 西安事变不是“七七事变”的前奏，二者性质不同。

一、【押题】全国统一大市场与“五统一、一开放”

1. 事件/政策事实

  • 中央财经委员会第六次会议：2025年7月1日上午，习近平主持召开，研究纵深推进全国统一大市场建设、海洋经济高质量发展等问题。
  • 基本要求“五统一、一开放”：
  1. 统一市场基础制度；
  2. 统一市场基础设施；
  3. 统一政府行为尺度；
  4. 统一市场监管执法；
  5. 统一要素资源市场；
  6. 持续扩大对内对外开放。
  • 中央经济工作会议衔接：2025年12月会议提出“纵深推进全国统一大市场建设”“制定全国统一大市场建设条例”“深入整治‘内卷式’竞争”。
  • 目标指向：降低交易成本、畅通国内大循环、提高资源配置效率，为构建新发展格局提供基础支撑。

2. 考点对接

  • 毛中特·社会主义市场经济：建设全国统一大市场，核心是处理好政府与市场的关系，做到既“放得活”又“管得好”；对应有效市场与有为政府相结合、要素市场化配置改革、高标准市场体系。
  • 毛中特·新发展格局：国内大循环为主体，前提是国内市场必须统一、畅通；地方保护、市场分割会抬高交易成本、削弱超大规模市场优势。统一大市场是构建新发展格局的基础支撑。
  • 马原：系统观念——全国统一大市场是系统工程，制度、设施、监管、要素要整体推进；联系的观点——各地各部门相互联系，市场分割人为割裂联系，阻碍生产力发展；整体与部分——局部利益服从整体利益。

3. 可能题型

  • 选择题陷阱：
  • “五统一、一开放”是五项统一＋一个开放，不是“五统一、一禁止”。
  • 统一的是“政府行为尺度”，不是“政府行为方式”。
  • “内卷式”竞争是中央经济工作会议的表述，不是“恶性竞争”的泛称。
  • 全国统一大市场建设条例是“制定”，不是“修订”。
  • 分析题设问：为什么说建设全国统一大市场是构建新发展格局的基础支撑？

答题链：新发展格局要求国内大循环为主体 → 统一大市场降低交易成本、畅通要素流动 → 超大规模市场优势转化为竞争优势 → 破除地方保护、市场分割 → 与高水平对外开放相互促进 → 结论。

  • 可替换设问：
  1. 如何理解“五统一、一开放”的内在逻辑？
  2. 整治“内卷式”竞争与建设统一大市场的关系。

4. 金句

  • “纵深推进全国统一大市场建设。”
  • “基本要求是‘五统一、一开放’。”
  • “制定全国统一大市场建设条例，深入整治‘内卷式’竞争。”

5. 易错点

  • 统一大市场≠统一价格：统一的是制度、设施、监管、要素市场，不是商品价格。
  • “一开放”是对内对外开放，不是只对外资开放。
  • 中央财经委会议是2025年7月1日，不是2026年。
  • 全国统一大市场不是“回到计划经济”，而是更好发挥市场在资源配置中的决定性作用。

（来源：中央财经委员会第六次会议；央视网）

二、【押题】抗战胜利81周年与正确二战史观

1. 事件/政策事实

  • 时间：2026年9月3日，中国人民抗日战争暨世界反法西斯战争胜利81周年纪念日。
  • 各地活动：辽宁沈阳“九·一八”历史博物馆依托2400余件珍贵文物、历史照片与影像资料开展沉浸式互动宣讲；南京侵华日军南京大屠杀遇难同胞纪念馆约500名社会各界人士参加纪念活动；各地围绕“弘扬伟大抗战精神 凝聚团结奋进力量”开展主题活动。
  • 历史坐标：1931年九一八事变→1937年七七事变全面抗战→1945年9月2日日本签署投降书、9月3日定为胜利纪念日；中国战场是世界反法西斯战争的东方主战场，中国人民抗日战争开始时间最早、持续时间最长。
  • 80周年对照：2025年9月3日举行纪念中国人民抗日战争暨世界反法西斯战争胜利80周年大会，习近平发表重要讲话；2026年为81周年，重在“铭记历史、缅怀先烈、珍爱和平、开创未来”。

2. 考点对接

  • 史纲·抗日战争：抗日民族统一战线（1937年9月正式形成）；中国共产党是抗战的中流砥柱（倡导、推动、维护统一战线，敌后战场，持久战战略）；十四年抗战（1931—1945）；南京大屠杀（1937年12月13日，30万同胞遇难）；正确二战史观。
  • 毛中特·外交：和平发展道路、人类命运共同体、维护战后国际秩序和以联合国为核心的国际体系。
  • 思修：爱国主义是中华民族精神的核心；伟大抗战精神（天下兴亡、匹夫有责的爱国情怀，视死如归、宁死不屈的民族气节，不畏强暴、血战到底的英雄气概，百折不挠、坚忍不拔的必胜信念）。

3. 可能题型

  • 选择题陷阱：
  • 2026年是81周年，不是80周年（80周年是2025年）。
  • 抗战胜利纪念日是9月3日，不是8月15日（8月15日日本宣布无条件投降）。
  • 十四年抗战起点是1931年九一八事变，全面抗战起点是1937年七七事变。
  • 南京大屠杀死难者国家公祭日是12月13日。
  • 分析题设问：为什么说中国共产党是抗日战争的中流砥柱？

答题链：最早举起抗日旗帜（九一八后）→ 倡导并推动抗日民族统一战线 → 提出持久战战略总方针 → 开辟敌后战场、坚持游击战争 → 维护团结、反对投降分裂 → 结论（政治领导、战略指导、精神引领）。

  • 可替换设问：
  1. 如何理解“正确二战史观”？
  2. 伟大抗战精神的内涵及其时代价值。

4. 金句

  • “铭记历史、缅怀先烈、珍爱和平、开创未来。”
  • “中国战场是世界反法西斯战争的东方主战场。”
  • “伟大的抗战精神，是中国人民弥足珍贵的精神财富。”

5. 易错点

  • 8月15日是日本宣布无条件投降，9月2日是签署投降书，9月3日是胜利纪念日，三个时间要分清。
  • 十四年抗战不是“八年抗战”；“八年”指全面抗战（1937—1945）。
  • 抗日民族统一战线正式形成的标志是1937年9月国民党公布中共中央提交的国共合作宣言，不是西安事变。
  • 中流砥柱是中国共产党，不是国民党正面战场。

（来源：央视网·各地纪念抗战胜利81周年；人民网）

三、【押题】第九届进博会与高水平对外开放

1. 事件/政策事实

  • 时间地点：2026年11月5日至10日，国家会展中心（上海）。
  • 规模：汇聚162个国家、地区和国际组织，4142家境外企业参展，整体面积首次突破44万平方米。
  • 出席：中共中央政治局常委、国务院副总理丁薛祥出席开幕式并作主旨讲话；同期举办虹桥国际经济论坛。
  • 定位：进博会是世界上首个以进口为主题的国家级展会，永久主题“新时代，共享未来”，是中国高水平对外开放的重要窗口。

2. 考点对接

  • 当代世界经济与政治：开放型世界经济、经济全球化、全球治理、多边贸易体制；中国以超大规模市场为世界提供机遇，反对单边主义、保护主义。
  • 毛中特·对外开放：高水平对外开放、制度型开放、双循环新发展格局、共享中国市场机遇；从“商品和要素流动型开放”走向“规则、规制、管理、标准等制度型开放”。
  • 马原：联系的普遍性（全球产业链供应链深度融合）；世界历史理论（世界市场使各国普遍交往）。

3. 可能题型

  • 选择题陷阱：
  • 第九届进博会是2026年11月5—10日，不是11月10—15日。
  • 进博会是“进口”为主题，不是出口。
  • 出席开幕式的是丁薛祥，不是李强。
  • 规模数字：162个国家地区国际组织、4142家境外企业、44万平方米。
  • 分析题设问：进博会如何体现“中国开放的大门不会关闭，只会越开越大”？

答题链：主动扩大进口（共享中国市场）→ 制度型开放（规则对接）→ 多边主义（反对保护主义）→ 双循环（以开放促改革促发展）→ 世界意义（为全球提供公共产品）。

  • 可替换设问：
  1. 进博会与构建新发展格局的关系。
  2. 为什么说“开放是当代中国的鲜明标识”？

4. 金句

  • “新时代，共享未来。”
  • “中国开放的大门不会关闭，只会越开越大。”
  • “让中国市场成为世界的市场、共享的市场、大家的市场。”

5. 易错点

  • 进博会≠广交会：进博会以进口为主题，广交会以出口为主。
  • 虹桥国际经济论坛是进博会的重要组成部分，不是独立会议。
  • 44万平方米是“整体面积首次突破”，不是“展览面积44万平方米”的旧数据。
  • 进博会是国家级展会，不是地方性展会。

（来源：商务部；新华网）

四、【押题】“人工智能+”行动与新质生产力

1. 事件/政策事实

  • 文件：2025年8月21日，国务院印发《关于深入实施“人工智能+”行动的意见》（国发〔2025〕11号）。
  • 六大重点行动：“人工智能+”科学技术、产业发展、消费提质、民生福祉、治理能力、全球合作。
  • 八项基础支撑：提升模型基础能力、加强数据供给创新、强化智能算力统筹、优化应用发展环境、促进开源生态繁荣、加强人才队伍建设、强化政策法规保障、提升安全能力水平。
  • 目标：到2027年，人工智能与6大重点领域广泛深度融合，新一代智能终端、智能体等应用普及率超70%；到2035年，我国全面步入智能经济和智能社会发展新阶段。
  • 中央经济工作会议衔接：“深化拓展‘人工智能+’，完善人工智能治理”。

2. 考点对接

  • 毛中特·新质生产力：新质生产力以科技创新为核心，具有高科技、高效能、高质量特征；“人工智能+”是科技创新与产业创新深度融合的重要抓手，推动传统产业转型升级、培育新兴产业和未来产业。
  • 马原：生产力与生产关系——人工智能是生产力发展的新引擎，同时要求生产关系（就业结构、分配方式、治理规则）相应调整；科学技术是第一生产力；矛盾——发展与安全、创新与治理要统筹。
  • 当代：全球人工智能治理、科技竞争与合作；中国主张以人为本、智能向善。

3. 可能题型

  • 选择题陷阱：
  • 文件是国务院《关于深入实施“人工智能+”行动的意见》，不是“规划”“方案”。
  • 六大行动包括“全球合作”，不只是科技、产业、消费、民生、治理。
  • 2027年目标是“应用普及率超70%”，2035年是“全面步入智能经济和智能社会”。
  • 文号是国发〔2025〕11号。
  • 分析题设问：为什么说“人工智能+”是发展新质生产力的重要引擎？

答题链：新质生产力的核心是科技创新 → 人工智能是通用目的技术，渗透性强 → 与产业融合催生新产业新模式 → 提升全要素生产率 → 推动高质量发展 → 同时要完善治理、统筹发展与安全。

  • 可替换设问：
  1. 如何理解“人工智能+”的“+”？
  2. 人工智能发展与就业的关系（马原：生产力与生产关系）。

4. 金句

  • “推动人工智能与经济社会各行业各领域广泛深度融合。”
  • “促进生产力革命性跃迁和生产关系深层次变革。”
  • “加快形成人机协同、跨界融合、共创分享的智能经济和智能社会新形态。”

5. 易错点

  • “人工智能+”不是“+人工智能”：前者是人工智能赋能各行业，后者是把人工智能当作被改造对象。
  • 2027/2035两个时间节点要对应准确。
  • “智能经济”与“智能社会”是并列的新形态，不要只答经济。
  • 文件是国务院印发，不是中共中央、国务院联合印发。

（来源：中国政府网·国发〔2025〕11号；新华网）

五、【押题】教育强国与教育科技人才一体化

1. 事件/政策事实

  • 文件：2025年1月，中共中央、国务院印发《教育强国建设规划纲要（2024—2035年）》，这是首个以教育强国为主题的国家行动计划。
  • 目标：到2035年建成教育强国；以教育强国支撑引领中国式现代化。
  • 战略定位：党的二十大指出，教育、科技、人才是全面建设社会主义现代化国家的基础性、战略性支撑；三者要一体推进。
  • 中央经济工作会议衔接：“制定一体推进教育科技人才发展方案”；建设北京（京津冀）、上海（长三角）、粤港澳大湾区国际科技创新中心。

2. 考点对接

  • 毛中特·教育科技人才：教育是国之大计、党之大计；科技是第一生产力、人才是第一资源、创新是第一动力；三者一体推进，才能形成合力。对应科教兴国战略、人才强国战略、创新驱动发展战略。
  • 毛中特·中国式现代化：中国式现代化需要高质量教育体系支撑；教育公平是社会公平的重要基础。
  • 马原：生产力与生产关系——人才是生产力中最活跃的因素；实践与认识——教育要与社会实践相结合；系统观念——教育、科技、人才是系统整体。

3. 可能题型

  • 选择题陷阱：
  • 纲要名称是《教育强国建设规划纲要（2024—2035年）》，不是“2025—2035”。
  • 目标是2035年建成教育强国，不是2025年、2050年。
  • “基础性、战略性支撑”是党的二十大的表述，指教育、科技、人才。
  • 首个以教育强国为主题的国家行动计划，不是“第一部教育法”。
  • 分析题设问：为什么必须一体推进教育科技人才发展？

答题链：三者内在关联（教育培养人才、人才支撑科技、科技引领发展）→ 中国式现代化的支撑 → 国际竞争实质是人才竞争 → 体制机制一体改革 → 形成合力。

  • 可替换设问：
  1. 如何理解“教育是国之大计、党之大计”？
  2. 教育公平与共同富裕的关系。

4. 金句

  • “教育、科技、人才是全面建设社会主义现代化国家的基础性、战略性支撑。”
  • “到2035年建成教育强国。”
  • “教育是国之大计、党之大计。”

5. 易错点

  • 教育强国与科教兴国不是同一概念：前者是目标/状态，后者是战略。
  • 纲要是“规划纲要”，不是“法律”。
  • “一体推进”不是“分别推进”，强调统筹协同。
  • 2035年与“基本实现社会主义现代化”同步，不要与2050年混淆。

（来源：新华网·教育强国建设规划纲要）

七、今日一题

选择题

2025年7月中央财经委员会第六次会议提出，纵深推进全国统一大市场建设的基本要求是“五统一、一开放”。下列不属于“五统一”的是（ ）

A. 统一市场基础制度
B. 统一市场基础设施
C. 统一政府行为尺度
D. 统一企业登记注册

答案：D。

解析：“五统一”是统一市场基础制度、统一市场基础设施、统一政府行为尺度、统一市场监管执法、统一要素资源市场；“一开放”是持续扩大对内对外开放。“统一企业登记注册”是具体改革举措，不属于“五统一”的规范表述。

分析题

材料：国务院《关于深入实施“人工智能+”行动的意见》提出，推动人工智能与经济社会各行业各领域广泛深度融合，加快形成智能经济和智能社会新形态。

问题：结合材料，说明“人工智能+”为什么是发展新质生产力的重要引擎，并分析发展中应注意的问题。

参考答案与评分点：

（1）为什么是引擎（6分）：

  • 新质生产力以科技创新为核心，人工智能是通用目的技术，渗透性强、带动面广；（2分）
  • 与产业深度融合，催生新产业、新模式、新动能，推动传统产业转型升级；（2分）
  • 提升全要素生产率，推动高质量发展，塑造国际竞争新优势。（2分）

（2）应注意的问题（4分）：

  • 统筹发展和安全，完善人工智能治理，确保始终处于人类控制之下；（1分）

答题提示：分析题先定性（新质生产力的核心是科技创新），再讲机制（渗透—融合—提效），最后讲治理（发展与安全辩证统一），体现“两点论”。

  2. 必须坚定不移推动高质量发展，不断满足人民日益增长的美好生活需要，统筹推进"五位一体"总体布局，协调推进"四个全面"战略布局，促进全体人民共同富裕；
  3. 必须勇于进行具有许多新的历史特点的伟大斗争，更好统筹发展和安全；
  4. 必须加快把人民军队建成世界一流军队，坚持党对人民军队的绝对领导，如期实现建军一百年奋斗目标；
  5. 必须坚持党的领导、加强党的建设，持之以恒推进全面从严治党。

2. 考点对接

  • 史纲：长征是中国革命史上的伟大转折。遵义会议（1935年1月）确立了毛泽东同志在党中央和红军的领导地位，是党的历史上一个生死攸关的转折点，标志着中国共产党在政治上开始走向成熟。长征的胜利，实现了中国革命重心由南方到北方的战略转移，为抗日民族统一战线的形成奠定了基础。
  • 毛中特：把长征精神与中国式现代化贯通。"五个必须"实际上是把革命年代的制胜之道转化为新时代的实践要求：高质量发展、共同富裕、统筹发展和安全、强军目标、全面从严治党——这正是当前考研政治的五条主线。
  • 马原：人民群众是历史的主体和创造者——长征胜利靠人民群众支持，这是群众史观的生动体现。实践与认识——长征是在极端困难条件下的伟大实践，遵义会议对"左"倾错误的纠正体现了认识在实践中深化。矛盾——长征途中敌我力量悬殊，但通过战略战术的灵活调整（四渡赤水等），实现了矛盾双方的转化。
  • 思修：理想信念是精神之"钙"；爱国主义与革命精神；艰苦奋斗、团结协作。

  • 毛中特：以人民为中心的发展思想；在发展中保障和改善民生；共同富裕（中国式现代化本质要求）；以人口高质量发展支撑中国式现代化；社会保障体系"覆盖全民、统筹城乡、公平统一、安全规范、可持续"。
  • 马原：矛盾的特殊性原理 → 具体问题具体分析（"四个把握"就是分层分类）；人民群众是历史的主体和创造者。
  • 思修：孝老爱亲的家庭美德；中华优秀传统文化"老吾老以及人之老"；社会主义核心价值观。
  • 易错："银发经济"既是民生事业，也是发展新动能；不是单纯的"养老负担"论。

3. 命题角度

  • 选择题：会议时间地点、指示中的"四个协同"、"四个把握"的具体对应。
  • 分析题：为什么说发展银发经济"既是民生工程，也是发展工程"？答题链：人口结构变化（客观趋势）→ 民生属性（以人民为中心、共同富裕）→ 经济属性（扩大内需、培育新增长点、有效市场与有为政府结合）→ 辩证统一（在发展中保障和改善民生）。

四、年度重点①：2026年全国两会与"十五五"规划纲要

1. 事实清单

  • 2026年3月5日，十四届全国人大四次会议开幕，李强作政府工作报告；会议审查批准《中华人民共和国国民经济和社会发展第十五个五年规划纲要》。

  • 分析题：如何理解"十五五"是"夯实基础、全面发力"的关键时期？→ 从2035远景目标倒推、从主要矛盾变化、从高质量发展主题展开。

七、今日一题

选择题1

2026年11月19日，亚太经合组织第三十三次领导人非正式会议在深圳举行。习近平发表的重要讲话题目是（ ）

A.《建设亚太共同体，续写"亚太奇迹"新篇章》
B.《携手构建亚太命运共同体》
C.《开放合作，共创亚太美好未来》
D.《推动亚太自由贸易区建设》

答案：A。 解析：会议主题是"建设亚太共同体，促进共同繁荣"，讲话标题是《建设亚太共同体，续写"亚太奇迹"新篇章》，二者要区分。B、C为形似干扰项；D是会议议题之一，不是讲话标题。

选择题2

习近平提出携手搭建亚太共同体的"四梁八柱"，下列不属于"四梁八柱"的是（ ）

A. 强化经贸支柱
B. 升级联通支柱
C. 打造创新支柱
D. 筑牢安全支柱

答案：D。 解析："四梁八柱"为经贸、联通、创新、发展四大支柱。安全合作体现在"发展支柱"的相关内容中，但"安全支柱"不是本次表述。

分析题（口述3分钟）

材料：习近平在APEC会议上指出，要"构建开放而不排他、融合而不分割的合作格局"。

问题：运用唯物辩证法联系的观点，说明为什么亚太各国"越来越成为你中有我、我中有你的命运共同体"。

答题框架：

  1. 原理：联系具有普遍性、客观性、多样性；世界历史理论揭示，生产社会化和国际分工使各民族进入普遍交往。
  2. 展开：产业链供应链、资本、技术、人员跨境流动，使各国利益深度交融；"脱钩断链"违背客观联系，必然损人害己。
  3. 方法论：坚持系统观念，用综合的、整体的思维方式认识世界；共商共建共享。
  4. 结论：开放包容、合作共赢是唯一正确选择，必须推动构建人类命运共同体。
