2. 讲话骨架（背这三层）

  • 形势判断：30多年来亚太创造了"亚太奇迹"；面对新机遇新挑战，亚太合作必须"适应新形势、迈出新步伐、开创新局面"。
  • 四个坚持：和衷共济（共同体意识）→ 开放融通（经济一体化）→ 开拓创新（科技与结构性改革）→ 包容发展（普惠共享）。
  • 中国行动：中国是亚太经济合作的倡导者、推动者、先行者；搭建"四梁八柱"；三点主张——坚定信心、把准方向、实干笃行，"抓住发展这个最大公约数"。

3. 知识点对接

  • 毛中特／当代：中国特色大国外交；推动构建人类命运共同体（"五个世界"：持久和平、普遍安全、共同繁荣、开放包容、清洁美丽）；开放型世界经济；全球治理观（共商共建共享）；正确义利观；中国式现代化是走和平发展道路的现代化。
  • 马原：联系的普遍性、客观性；世界历史理论（国际分工与世界市场使各民族形成普遍交往）；矛盾普遍性与特殊性（"亚太奇迹"是个性，共同发展规律是共性）。
  • 金句："构建开放而不排他、融合而不分割的合作格局"。
  • 易错：亚太自由贸易区是"共同愿景""稳步推进"，不是已建成；"四梁八柱"不含"安全支柱"。

4. 命题角度

  • 选择题：主题、讲话标题、举办城市、成果文件名称、2027年东道主。
  • 分析题：为什么中国主张"开放而不排他、融合而不分割"？答题链：时代背景（百年变局＋保护主义逆流）→ 理论依据（命运共同体、正确义利观、全球治理观）→ 实践举措（四梁八柱、制度型开放、高质量共建"一带一路"）→ 世界意义（为亚太和世界注入确定性）。

二、中俄美元首会晤与《中俄美元首和平宣言》

1. 事实清单

  • 11月19日下午，习近平在深圳同俄罗斯总统普京、美国总统特朗普举行中俄美元首会晤，主题为"维护世界和平，促进大国关系战略稳定"。
  • 据《人民日报》报道，这是中俄美三国最高领导人有史以来首次聚首，具有开创性意义；会后发表《中俄美元首和平宣言》。
  • 习近平提出四点看法：坚持相互尊重、坚持和平共处、坚持合作共赢、坚持对话协商。
  • 涉及议题：乌克兰危机、防止核武器扩散、中东局势、朝鲜半岛等。
  • 同日，习近平会见美国总统特朗普：中美关系新定位为"建设性战略稳定关系"，内涵是"基于尊重、公平、对等"；双方同意制定行动计划；美方表示不支持"台独"。

2. 金句与判断（分析题可直接引用）

  • "大国和则世界安，大国斗则世界乱。"
  • "'修昔底德陷阱'绝不是宿命，关键要看主要大国如何抉择。"
  • "核战争打不赢也打不得。"
  • "以对话聚共识，以担当迎挑战，以合作促和平。"

3. 知识点对接

  • 毛中特／当代：独立自主的和平外交政策；新型国际关系（相互尊重、公平正义、合作共赢）；大国关系格局（和平共处、总体稳定、均衡发展）；全球安全倡议；共同、综合、合作、可持续的安全观；真正的多边主义。
  • 史纲：世界反法西斯战争胜利；中俄美同为二战主要战胜国；维护战后国际秩序和《联合国宪章》宗旨；正确二战史观。
  • 马原：矛盾的对立统一（大国之间竞争与合作并存，斗争性与同一性相互联结）；系统观念（"六个必须坚持"之一）。
  • 思修：和平、发展、公平、正义、民主、自由的全人类共同价值。

4. 命题角度

  • 选择题：会晤地点与主题、"首次"、四点看法、宣言名称、中美新定位表述。
  • 分析题：如何理解"修昔底德陷阱不是宿命"？答题链：否定"国强必霸"逻辑（中国式现代化走和平发展道路）→ 大国责任（联合国安理会常任理事国、二战战胜国）→ 中国方案（相互尊重、和平共处、合作共赢、对话协商）→ 实践意义（战略稳定、危机管控、全球治理）。

三、习近平对老龄工作作出重要指示；全国老龄工作会议召开

1. 事实清单

  • 全国老龄工作会议11月18—19日在北京召开，传达习近平重要指示；李强出席会议并讲话。
  • 指示核心：深入实施积极应对人口老龄化国家战略，坚持政府、市场、社会、家庭协同发力，加强老年人社会保障、养老服务、健康服务、社会参与，大力发展银发经济，建设老年友好社会。
  • 李强提出"四个把握"：
  1. 把握年龄和健康状况差异 → 老有所养与老有所为相统筹；
  2. 把握经济条件差异 → 服务保障梯度供给；
  3. 把握养老方式差异 → 居家、社区、机构服务贯通协调；
  4. 把握城乡区域分布差异 → 政策均衡性、精准性。
  • 目标节点：锚定"十五五"目标任务，解决老年人急难愁盼问题。

2. 知识点对接

  • 毛中特：以人民为中心的发展思想；在发展中保障和改善民生；共同富裕（中国式现代化本质要求）；以人口高质量发展支撑中国式现代化；社会保障体系"覆盖全民、统筹城乡、公平统一、安全规范、可持续"。
  • 马原：矛盾的特殊性原理 → 具体问题具体分析（"四个把握"就是分层分类）；人民群众是历史的主体和创造者。
  • 思修：孝老爱亲的家庭美德；中华优秀传统文化"老吾老以及人之老"；社会主义核心价值观。
  • 易错："银发经济"既是民生事业，也是发展新动能；不是单纯的"养老负担"论。

3. 命题角度

  • 选择题：会议时间地点、指示中的"四个协同"、"四个把握"的具体对应。
  • 分析题：为什么说发展银发经济"既是民生工程，也是发展工程"？答题链：人口结构变化（客观趋势）→ 民生属性（以人民为中心、共同富裕）→ 经济属性（扩大内需、培育新增长点、有效市场与有为政府结合）→ 辩证统一（在发展中保障和改善民生）。

四、年度重点①：2026年全国两会与"十五五"规划纲要

1. 事实清单

  • 2026年3月5日，十四届全国人大四次会议开幕，李强作政府工作报告；会议审查批准《中华人民共和国国民经济和社会发展第十五个五年规划纲要》。
  • 2026年经济增长预期目标：4.5%—5%（"在实际工作中努力争取更好结果"）。
  • "十五五"规划纲要贯彻落实党的二十届四中全会《建议》，细化提出20项主要指标，分领域部署重大战略任务，突出推动高质量发展、做强国内大循环等。
  • 政策取向：坚持内需主导，统筹促消费和扩投资；强调"投资于人"；加紧培育壮大新动能、加快高水平科技自立自强；提高民生类政府投资比重。
  • "十五五"时期（2026—2030年）定位：基本实现社会主义现代化夯实基础、全面发力的关键时期；为2035年人均国内生产总值比2020年翻一番、达到中等发达国家水平打好基础。

2. 知识点对接

  • 毛中特：高质量发展是全面建设社会主义现代化国家的首要任务；构建新发展格局（以国内大循环为主体、国内国际双循环相互促进）；实施扩大内需战略；发展新质生产力；全体人民共同富裕；统筹发展和安全；规划治理是中国式现代化的重要方式（一张蓝图绘到底）。
  • 马原：量变与质变（"十五五"为2035远景目标打基础）；生产力与生产关系、经济基础与上层建筑矛盾运动；系统观念。
  • 时政选择：GDP目标4.5%—5%；20项指标；"十五五"起止2026—2030；四中全会《建议》→ 两会《纲要》的法定程序。

3. 命题角度

  • 为什么强调"投资于人"？答题链：人力资本是第一资源→ 扩大内需与消费升级→ 人口高质量发展→ 共同富裕。
  • 分析题：如何理解"十五五"是"夯实基础、全面发力"的关键时期？→ 从2035远景目标倒推、从主要矛盾变化、从高质量发展主题展开。

五、年度重点②：2026年中央一号文件

1. 事实清单

  • 2026年1月3日，《中共中央 国务院关于锚定农业农村现代化 扎实推进乡村全面振兴的意见》发布。
  • 2026年是"十五五"开局之年，"做好'三农'工作至关重要"。
  • 主线：锚定农业农村现代化，扎实推进乡村全面振兴。
  • 重点任务：提升农业综合生产能力和质量效益（稳定发展粮油生产）；提升农业科技创新效能，因地制宜发展农业新质生产力（促进人工智能与农业发展结合）；积极促进农民稳定增收；因地制宜推进宜居宜业和美乡村建设；推动城乡要素双向流动；加强农村基层党组织建设。

2. 知识点对接

  • 毛中特：农业农村现代化是中国式现代化的根基；乡村全面振兴（产业、人才、文化、生态、组织"五个振兴"）；粮食安全是"国之大者"；城乡融合发展；共同富裕。
  • 马原：矛盾普遍性与特殊性（因地制宜）；科学技术是第一生产力（农业新质生产力）。
  • 易错：一号文件主题是"农业农村现代化＋乡村全面振兴"，不是单一"粮食安全"；"农业新质生产力"是新提法。

3. 命题角度

  • 选择题：文件名称、发布时间、主题主线、新提法（农业新质生产力）。
  • 分析题：为什么说"强国必先强农，农强方能国强"？→ 中国式现代化全局、粮食安全底线、城乡融合发展、农民增收与共同富裕。

七、今日一题

选择题1

2026年11月19日，亚太经合组织第三十三次领导人非正式会议在深圳举行。习近平发表的重要讲话题目是（ ）

A.《建设亚太共同体，续写"亚太奇迹"新篇章》
B.《携手构建亚太命运共同体》
C.《开放合作，共创亚太美好未来》
D.《推动亚太自由贸易区建设》

答案：A。 解析：会议主题是"建设亚太共同体，促进共同繁荣"，讲话标题是《建设亚太共同体，续写"亚太奇迹"新篇章》，二者要区分。B、C为形似干扰项；D是会议议题之一，不是讲话标题。

选择题2

习近平提出携手搭建亚太共同体的"四梁八柱"，下列不属于"四梁八柱"的是（ ）

A. 强化经贸支柱
B. 升级联通支柱
C. 打造创新支柱
D. 筑牢安全支柱

答案：D。 解析："四梁八柱"为经贸、联通、创新、发展四大支柱。安全合作体现在"发展支柱"的相关内容中，但"安全支柱"不是本次表述。

分析题（口述3分钟）

材料：习近平在APEC会议上指出，要"构建开放而不排他、融合而不分割的合作格局"。

问题：运用唯物辩证法联系的观点，说明为什么亚太各国"越来越成为你中有我、我中有你的命运共同体"。

答题框架：

  1. 原理：联系具有普遍性、客观性、多样性；世界历史理论揭示，生产社会化和国际分工使各民族进入普遍交往。
  2. 展开：产业链供应链、资本、技术、人员跨境流动，使各国利益深度交融；"脱钩断链"违背客观联系，必然损人害己。
  3. 方法论：坚持系统观念，用综合的、整体的思维方式认识世界；共商共建共享。
  4. 结论：开放包容、合作共赢是唯一正确选择，必须推动构建人类命运共同体。
